How to play

Goal

Move every seed into the store on the left.

How it works

  • The pits are numbered 1, 2, 3 and so on, counting away from the store.
  • Tap a pit to pick up all its seeds and sow them one by one into the pits towards the store, finishing in the store.
  • A move is only allowed if the last seed lands exactly in the store, which means the pit must hold exactly as many seeds as its number. Pit 3 needs exactly 3 seeds. Pits that can be played glow peach.
  • If no pit can be played and seeds remain, you're stuck. Use Undo and try a different order.
  • Choose how many seeds to start with. Every starting position can be solved.

Tips

  • When more than one pit is ready, the ready pit nearest the store is always the right choice. Playing a far pit first tends to overfill the near ones.
  • Watch how sowing from a far pit adds one seed to each pit in between, and plan for which pits that will make ready.

The history of Tchoukaillon

Tchoukaillon is a one-player puzzle based on Tchouka, a sowing game from Central Asia, part of the large mancala family of seed games. It was described as a solitaire in 1977, and mathematicians have studied it because each number of seeds has exactly one solvable starting position.
