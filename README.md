# Mind Games

Calm puzzle and mind games from around the world. A static, installable web app (PWA) — no build step.

- `index.html` — game list
- `games/15-puzzle/` — the 15-Puzzle
- `styles.css` — shared styles; palette from recent Pantone Colors of the Year

Run locally: `python -m http.server -d .` then open http://localhost:8000.
